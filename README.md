# Mon Ciné

App iPhone (SwiftUI, iOS 26) : films TMDB, séances AlloCiné, favoris, notes, agenda, billets et cartes prépayées.

IPA : https://github.com/Cyprdu/mon-cine/releases/latest/download/MonCine.ipa (non signé : SideStore, AltStore ou Sideloadly).

Aucune clé ni billet dans ce dépôt : la clé TMDB se saisit dans l’app.

Ce produit utilise l’API TMDB mais n’est ni approuvé ni certifié par TMDB.
